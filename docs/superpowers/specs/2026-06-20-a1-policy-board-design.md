# A1 政经良性循环展板设计

日期：2026-06-20

## 背景

现有 A1 展板为 4 张，位于 `static/exhibition_boards/`，通过 `index.html` + `boards.css` 组织版式，并由 `tools/render_exhibition_board_previews.py` 导出单张预览与合并预览。用户希望新增第 5 张 A1，用于补充“策略和经济政策策划”部分，重点表达政府、市场、居民三方之间的良性循环。

本设计已确认采用 A+B 混合方向：以“政府-市场-居民良性循环”为主视觉，同时加入经济政策工具和运营指标，形成政策机制与经济可行性并重的压轴展板。

## 目标

新增一张 A1 竖版展板，题名暂定为“政经良性循环与实施政策策划”。展板需要完成三件事：

1. 讲清楚政府、市场、居民三方如何形成正向循环。
2. 展示可执行的经济政策工具，包括财政、税费、租金、运营、社区基金和绩效复盘。
3. 使用图像生成工具生成 A3 小图纸，经 Real-ESRGAN x4plus 超分后拼入 A1，保证大幅面展示清晰度。

## 内容设计

### A1 总体结构

采用推荐版式：

- 上半部左侧为主视觉：三方良性循环机制图。
- 上半部右侧为经济政策工具栏：按“政府工具、市场工具、居民收益、治理复盘”分组。
- 底部为 4 张 A3 小图纸摘要：每张小图纸以统一风格生成、超分、再嵌入 A1。

主视觉表达逻辑：

- 政府：规则制定、财政引导、控规弹性、公共空间投入、监管与绩效评估。
- 市场：投资导入、轻资产运营、业态更新、租金分成、就业岗位创造。
- 居民：公共服务改善、就业增收、消费回流、社区基金共治、生活品质提升。
- 循环闭环：公共投入提升环境，环境吸引市场运营，市场收益反哺社区，居民参与提升治理绩效，治理绩效继续支持政策投入。

### A3 小图纸

新增 4 张 A3 图纸位图，作为第五张 A1 的图面素材：

1. `A3-1 三方良性循环机制图`
   - 表达政府、市场、居民三方角色、权责和收益流向。
   - 图面以循环箭头、节点卡片、核心共识区为主。

2. `A3-2 政策工具矩阵图`
   - 横轴为主体：政府、平台公司、社会资本、社区组织、居民。
   - 纵轴为工具：财政奖补、税费减免、租金策略、PPP/轻资产运营、社区基金、绩效复盘。

3. `A3-3 市场运营与收益回流图`
   - 表达“业态导入-客流提升-租金/经营收入-社区再投入”的资金与运营链条。
   - 可结合五个重点地块，展示差异化运营模型。

4. `A3-4 居民收益与治理反馈图`
   - 表达居民获得公共服务、就业机会、空间品质、社区基金收益，并通过协商机制反馈治理。
   - 强调“民生改善不是结果说明，而是经济循环中的稳定器”。

## 生成流程

### 文本生成

使用项目中的 DeepSeek LLM 生成政策策划文本。优先复用 `src.engines.llm_engine.call_llm_engine`，生成内容包括：

- A1 标题、副标题、主说明文字。
- 三方循环机制的节点文案。
- 经济政策工具栏文案。
- 4 张 A3 小图纸的图题、说明、图面提示词。

如果 DeepSeek API 不可用，脚本应输出明确错误，并允许使用静态兜底文本继续排版预览。

### 图像生成

图像生成使用 Codex 侧图像生成工具，而不是本地 SD WebUI。生成目标为 4 张统一视觉风格的 A3 政策图纸位图。提示词由 DeepSeek 文本阶段产出，再由实现脚本整理成适合图像生成的英文/中英混合视觉提示。

图纸风格要求：

- 城市规划竞赛图纸风格。
- 清晰的信息图结构、流程箭头、政策矩阵、经济循环图。
- 白底或浅灰底，深色标题，红、蓝、青、橙作为主体色。
- 避免大量难以辨识的小字；正式中文说明由 A1 HTML/CSS 叠加或在图下 caption 中呈现。

### 超分增强

每张 A3 图纸生成后，调用项目内本地 Real-ESRGAN：

`tools/realesrgan-ncnn-vulkan/realesrgan-ncnn-vulkan.exe`

模型使用：

`realesrgan-x4plus`

输出要求：

- 对 4 张 A3 图纸分别执行 x4 超分。
- 保留原图和超分图，便于回退。
- A1 拼版只引用超分图。

建议输出目录：

- 原始生成图：`static/exhibition_boards/policy_a3/generated/`
- 超分图：`static/exhibition_boards/policy_a3/upscaled/`

## A1 集成

需要在 `static/exhibition_boards/index.html` 中新增第 5 个 `.print-board` section，类名建议为 `board-05`。同时在 `static/exhibition_boards/boards.css` 中新增对应布局样式。

`tools/render_exhibition_board_previews.py` 需要从固定 4 张输出改为支持 5 张：

- `a1_board_01_preview.png`
- `a1_board_02_preview.png`
- `a1_board_03_preview.png`
- `a1_board_04_preview.png`
- `a1_board_05_preview.png`
- `a1_boards_competition_preview.png`

`tools/export_a1_editable_psd_package.py` 中 README 文案目前写死 4 张，也应同步改为动态数量或更新为 5 张，避免 PSD 包说明过期。

## 错误处理

- DeepSeek 不可用：停止自动政策生成，打印原因；允许实现时使用静态兜底 JSON 继续验证排版。
- 图像生成失败：保留文本与 SVG/HTML 占位图，不阻塞 A1 版式开发。
- Real-ESRGAN 不可用：检查 exe 和 `realesrgan-x4plus` 模型文件；失败时保留原始图，但在最终交付说明中明确未完成超分。
- A1 截图失败：Playwright 等待所有图片加载，若图片缺失，报出具体文件路径。

## 验证计划

实现完成后需要验证：

1. DeepSeek 文本生成脚本可运行，输出结构化政策内容。
2. 4 张 A3 图纸原图存在，并有对应 x4 超分图。
3. 新增 `board-05` 在浏览器中正常显示，图像不变形、不溢出。
4. `tools/render_exhibition_board_previews.py` 成功导出 5 张单板预览和合并预览。
5. 视觉检查第五张 A1：主循环图、经济工具栏、底部 A3 图纸层级清楚，文字不重叠。
6. 若更新 PSD 导出包，确认 manifest 包含第 5 张展板。

## 非目标

- 本次不重排前 4 张 A1 的版式。
- 本次不替换现有 A3 图册体系。
- 本次不依赖本地 SD WebUI 或 ControlNet。
- 本次不把 AI 生成图里的小字作为最终可读正文；可读正文应由 HTML/CSS 文本层承担。
