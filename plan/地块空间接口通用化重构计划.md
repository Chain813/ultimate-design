# 地块空间接口参数化与通用化重构计划

## 目标
消除项目中硬编码的“长春伪满皇宫周边街区”空间位置、初始地图参数、地理投影系统以及地标数据，实现 100% 配置驱动。使平台能够通过修改单一配置文件，一键适配并切换到其他城市及地块。

## 提议的变更

### 1. 配置文件定义

#### [MODIFY] [config.yaml](file:///e:/AI-based-project/urban-platform/config/config.yaml)
在配置文件末尾增加 `site` 空间属性组：
- `site_name` & `city_name`：地块名称与城市名称
- `local_crs`：本地高精度投影 EPSG 代号，用于物理测算
- `map_viewport`：中心经纬度 `[lng, lat]`、Zoom、Pitch、Bearing
- `landmarks`：供 Matplotlib 矢量大图渲染和地图定位标注的动态地标名录

---

### 2. 空间元数据获取接口

#### [NEW] [site.py](file:///e:/AI-based-project/urban-platform/src/config/site.py)
新建地块参数访问辅助模块，提供面向各个页面的标准 API：
- `get_site_config() -> dict`
- `get_site_center() -> list[float]`
- `get_map_viewport() -> dict`
- `get_local_crs() -> str`
- `get_landmarks() -> list[dict]`

---

### 3. WebGL 3D 地图引擎动态注入

#### [MODIFY] [map3d_standalone.html](file:///e:/AI-based-project/urban-platform/assets/map3d_standalone.html)
- 废弃硬编码的 `viewState` 经纬度与高度参数。
- 引入 `/*__MAP_CONFIG__*/` 模板替换标记。在运行时读取配置，初始化 Deck.GL 的 `viewState`。

#### [MODIFY] [datav_bigscreen.html](file:///e:/AI-based-project/urban-platform/assets/datav_bigscreen.html)
- 同步引入 `/*__MAP_CONFIG__*/` 模板替换占位符，支持动态中心点定位与视口自适应。

#### [MODIFY] [digital_twin.py](file:///e:/AI-based-project/urban-platform/src/ui/digital_twin.py)
- 修改 `render_digital_twin_map` 逻辑，在载入 HTML 模板时，读取 `config.yaml` 中的 `site.map` 参数，并序列化注入 `map3d_standalone.html`。

#### [MODIFY] [14_数据大屏.py](file:///e:/AI-based-project/urban-platform/pages/14_数据大屏.py)
- 同步读取配置文件中的地图参数，并将其注入 `datav_bigscreen.html`。

---

### 4. 2D 制图地标接口解耦

#### [MODIFY] [draw_scope_map.py](file:///e:/AI-based-project/urban-platform/tools/draw_scope_map.py)
- 重构主绘图底图组件中的地标标注绘制逻辑。
- 废弃硬编码在代码内部的 `("伪满皇宫博物院", 125.3422, 43.9036)` 等定位点，修改为遍历从 `src.config.site.get_landmarks()` 返回的动态列表。

## 验证计划

### 自动化测试
```powershell
python -m pytest tests/test_startup_smoke.py
```
确保重构后平台所有页面正常拉起并编译成功，没有因为导入冲突引发 `NameError` 或 `KeyError`。

### 手动验证
1. 运行 `run_desktop.bat` 或 `streamlit run app.py`。
2. 检查主页 3D 地图和“数据大屏” 3D 地图的初始视角 and 旋转中心是否与 `config.yaml` 设定的经纬度一致。
3. 检查大屏及各阶段页面加载的空间地标标签是否正确渲染。
